# محور | MAHVOR

سایت استاتیک فروشگاه مبلمان محور، آماده انتشار با GitHub Pages.

## انتشار
1. همه فایل‌های این پوشه را در ریشه یک Repository روی GitHub قرار دهید.
2. در **Settings → Pages** گزینه **Deploy from a branch** را انتخاب کنید.
3. Branch را روی `main` و Folder را روی `/ (root)` بگذارید.
4. فایل اصلی سایت `index.html` است.

## صفحات دسته‌بندی
صفحات دسته‌بندی به صورت فایل‌های مستقل HTML در کنار `index.html` قرار دارند و لینک‌های آن‌ها نسبی هستند.
